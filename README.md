# Spill the Tea ☕
 
Spill the Tea is a social platform designed to allow users to anonymously share stories, opinions, and discussions with a community. The system focuses on user interaction, privacy, and secure management of user information. Users are able to create accounts, share posts, interact with other users through comments and reactions, and access features based on their user roles and permissions.

The project is developed using Node.js and Express.js for the backend, with PostgreSQL used as the database system for storing and managing user information, posts, comments, and other application data. The project uses tools such as Git and GitHub for version control and Visual Studio Code for development.

To install the project, first clone the repository using Git, open the project folder, and install the required dependencies using `npm install`. The PostgreSQL database must then be set up by creating the required database and configuring the `.env` file with the correct database connection details.

Once the setup is complete, the application can be started by running `node server.js` in the project directory. The server will then run locally, allowing the system to connect to the database and provide access to the application features.

The purpose of Spill the Tea is to demonstrate the development of a secure, database-driven social platform while applying software development principles, backend programming, database management, and system security practices.
